# 深海生物知识图谱构建进展汇报

> **项目**：Ocean-DePTH-VLM —— 深海生物智能识别与知识服务体系
> **日期**：2026-10-30（数据截至本日）
> **说明**：本文为面向甲方/协作团队的进展汇报材料，重点介绍数据集搜集整理与知识图谱构建方法。

---

## 一、项目概述

项目以"检测 — 检索 — 判读 — 入库"闭环为核心，构建**可持续自动生长的深海生物知识图谱**：

- 一张深海原位图像进库后，自动完成生物检测、特征提取、知识检索、大模型判读，并结构化写入图数据库；
- 图谱以 **WoRMS 世界海洋物种登记册**的权威分类体系为骨架，挂接原位图像与形态型知识条目；
- 全部组件支持**单卡部署**（A40 级别即可运行），具备向科考船端和业务平台推广的基础。

**三大核心指标**

| 指标 | 数值 |
|---|---|
| 知识图谱节点总量 | **302,397** |
| 向量检索库 | **36,147** 条框切图嵌入（BioCLIP 2.5 · 1,024 维） |
| 自训检测模型 | **34 纲**（YOLO11m 双路） |

## 二、数据集搜集与整理

### 2.1 多源异构数据搜集

面向 **2,641 个物种 / 形态型条目**（统一唯一 ID 管理），图像与文本双通道同步推进：

| 数据源 | 条目数 | 说明 |
|---|---|---|
| FathomNet 在线图像库 | 1,475 项 | in-situ 原位底栖生态图像的主要来源（FNM_ 前缀） |
| MBARI 视频标注 | 524 项 | 深海 ROV 视频人工标注物种条目（MSP_ 前缀） |
| WDS 深海数据集 | 268 项 | 世界数据中心发表的深海观测数据（WDS_ 前缀） |
| 馆藏 / 专项图集 | 374 项 | 30 类馆藏前缀（HOL 59、POR 39、ACT 37、HEX 33 等） |
| APSMA 图集 PDF | 186 条 | MinerU 布局解析 + LLM 辅助结构化提取 |
| 西太图集 OCR | 专项 | 西太平洋图集文本 OCR 与人工校对流程沉淀 |

### 2.2 物种知识文本库采集

采用**三路递进**的采集策略，最终形成统一的结构化知识文本：

| 采集批次 | 成功条数 | 说明 |
|---|---|---|
| 网页版试采（batch_100） | 100 条 | 验证提示词与知识结构方案 |
| 早期批量采集 | 259 条 | 单模型批量管线验证 |
| **MaaS 双模型采集（主力）** | **1,785 条** | GLM-5.3 + DeepSeek-V4.1-Flash 双模型 5 路并发，补齐轮持续递增 |

- **去重覆盖**：三路并集 **2,144 / 2,641 条（81.2%）**，其余 497 条由自动补齐轮滚动重跑（脚本只跳过成功条目，失败条目自动重试）；
- **单条质量**：均值 1,932 字 / 中位 1,868 字 / 最长 4,760 字；设 ≥300 字入库门槛，杜绝空洞生成；
- **知识结构**：每条含五节结构化内容——分类地位、形态特征、地理与深度分布、生态习性、命名与同物异名；
- **工程保障**：429/503 自动退避重试、cache 断点续跑、双模型互为备份。

### 2.3 图像检测数据集

| 项目 | 数值 |
|---|---|
| 训练图像 | 123,703 张（FathomNet 底栖框标注） |
| 验证图像 | 30,998 张（独立划分，防泄漏） |
| 类别体系 | 34 类（33 个纲/门级阶元 + Other，源自 FathomNet 2,553 细类折叠，详见下文） |
| 训练配置 | YOLO11m · 120 epochs · imgsz 960 |
| 推理策略 | 同权重双路融合（详见下文） |

**类别体系构建：FathomNet 2,553 细类 → 34 纲级**（`06d_build_class_yolo.py`）

检测类别从 FathomNet 官方标注的 2,553 个细粒度 concept 类别折叠而来：

1. 每个 concept 经 WoRMS 分类链映射到纲级阶元；
2. 纲名归并：Teleostei→Actinopterygii（辐鳍鱼）、Stenolaemata→Gymnolaemata（苔藓虫统一）；
3. 框数 < 50 的低频纲（鸟、海洋哺乳类、桡足类等 7 个）并入 Other；
4. 器械/垃圾类及无法定纲的类别丢弃；
5. 最终 33 个纲/门级阶元（按框数降序）+ Other = 34 类。

与知识库形态型体系的关系：YOLO 纲级类别与图谱形态型通过 WoRMS 权威分类桥接（`07g_worms_phylum_mapping.py` 建立纲级映射），使 YOLO 检测结果能直接翻译为图谱分类语言。

**推理策略详解：同权重双路融合**（`scripts/utils/yolo_infer.py`）

不对模型重训，用同一份 34 纲权重（训练 imgsz=960）跑两套互补的推理视图，取并集提升检出：

| 推理路 | 配置 | 作用 |
|---|---|---|
| 路 1 | imgsz=960 + TTA（测试时增强） | 与训练尺度一致的主路；TTA 多尺度/翻转聚合，提升稳定检出 |
| 路 2 | imgsz=1920 原生高分辨率 | 捕捉小目标与远处个体；单独使用反而略差（超出训练尺度分布），但与路 1 高度互补 |

关键机制：

1. **极低置信度阈值（conf=0.05）**：检测层刻意"宁多勿漏"，低分框也保留；
2. **逐类贪心 NMS 合并（IoU 0.55）**：两路检测按置信度降序合并，同类重叠框去重保留高者，**不同类不互斥**——跨类别的模糊候选全部留给下游判别；
3. **误检兜底链**：多检出的误检由检索层拒识阈值（~0.90）过滤、大模型细判剔除，保证"多而不脏"；
4. **工程细节**：高分辨率路自动降 batch（imgsz≥1536 时 batch=16）防显存溢出，每路推理后清空 GPU 缓存。

实测结论：双路并集显著高于任一单路；再叠加第三路（1280 切片）仅边际提升，推理侧已接近饱和。

### 2.4 向量特征库（检索基础）

嵌入模型统一采用 **BioCLIP 2.5（ViT-H/14，1,024 维）**——生物分类专用对比学习模型，由 BioCLIP 1.0（512 维）整体升级：

| 库 | 规模 | 说明 |
|---|---|---|
| **向量检索库（EntryImage）** | **36,147 条** | 框切图级 1,024 维嵌入，Neo4j 向量索引 ONLINE |
| ├─ FathomNet 框切图 | 27,342 条 | 整帧→框切图替换已完成（整帧 0 残留） |
| ├─ YOLO 框切图 | 4,977 条 | 多框帧选优后选中框嵌入 |
| ├─ 图集插图 | 1,600 条 | 科研插图（无检测框，整图提特征） |

| 类目覆盖 | 8,047 形态型 | WoRMS 分类 7,240 + FathomNet 类别 807 |

## 三、知识图谱构建（重点）

### 3.1 图谱模式（Schema）设计

图谱采用"**权威分类骨架 + 条目挂接 + 图像证据**"的三层设计：

| 节点类型 | 数量 | 含义 |
|---|---|---|
| `WoRMSTaxon` | 263,609 | WoRMS 权威分类单元（门→纲→目→科→属→种完整谱系） |
| `EntryImage` | 36,147 | 原位/标本示例图像节点 |
| `Morphospecies` | 2,641 | 深海形态型知识条目（本项目核心对象） |
| **合计** | **302,397** | |

| 关系类型 | 数量 | 含义 |
|---|---|---|
| `BELONGS_TO` | 259,100 | 形态型条目 → 分类阶元归属链 |
| `HAS_IMAGE` | 36,147 | 条目 → 示例图像挂接 |
| `WORMS_MATCHED` | 2,543 | 条目 → WoRMS 权威分类精确对齐 |
| **合计** | **297,790** | |

设计思想：

1. **骨架先行**——先落 WoRMS 全量分类树，保证任何条目都能挂到权威谱系上，避免自造分类体系导致的碎片化；
2. **条目为中心**——Morphospecies 是知识与图像的汇聚点，向上挂分类链、向下挂图像证据；
3. **可生长**——Schema 对新条目、新图像、新关系完全开放，管线每跑一轮图谱自动增厚。

### 3.2 构建流程总览

全链路脚本化（`scripts/` 目录），每一步可独立重跑：

```
图像与标注获取        文本知识解析         特征与对齐                 图谱落库                 图谱应用
─────────────       ─────────────       ─────────────────         ─────────────────       ─────────────
01_download_fathomnet   06_parse_apsma      07h_bioclip25_embeddings   09_build_knowledge_graph  10_graphrag_pipeline
02_filter_benthicnet                        07b/c/f_insitu_embeddings  09b_import_worms_taxonomy 10b_graphrag_retrieval_test
03_convert_to_yolo                          07e_expand_knowledge_base  09c_rebuild_kg_bioclip25
05d/06d_train_yolo                          07g_worms_phylum_mapping   09d_rebuild_wormstaxon
                                            08_build_alignment_matrix  09e_enrich_descriptions
                                                                       09f_backfill_lineage
```

### 3.3 WoRMS 权威分类骨架构建（26.3 万节点）

WoRMS（World Register of Marine Species）是全球海洋物种的权威登记册。骨架构建分四步：

1. **分类树拉取与导入**（`09b_import_worms_taxonomy.py`）：通过 WoRMS 接口按谱系批量拉取分类单元，落库为 `WoRMSTaxon` 节点，含分类阶元（rank）、学名、权威 AphiaID 等属性；
2. **谱系回填**（`09f_backfill_lineage.py`）：对每个分类单元回填完整的"门→纲→目→科→属→种"祖先链，使任意两个分类单元在图上可达，支撑后续的图谱遍历式检索；
3. **纲级映射**（`07g_worms_phylum_mapping.py`）：建立 WoRMS 纲级类别与自训 YOLO 34 纲检测体系的映射表，让检测结果可以直接翻译成图谱分类语言；
4. **重建与清洗**（`09d_rebuild_wormstaxon.py`）：幂等重建脚本，保证骨架可随 WoRMS 版本更新而刷新。

### 3.4 形态型条目与图像挂接

- **条目入库**：2,641 条形态型条目以唯一 mid（FNM_/MSP_/WDS_/馆藏前缀）批量创建 `Morphospecies` 节点，写入五节结构化知识文本；
- **图像下载**（`download_species_images.py`）：按条目批量抓取原位/标本图像，创建 `EntryImage` 节点并以 `HAS_IMAGE` 挂接，共 36,147 张；
- **权威对齐**：条目学名经 WoRMS 精确匹配后建立 `WORMS_MATCHED` 关系（当前 2,543 条精确对齐），未精确匹配的条目通过 `BELONGS_TO` 挂靠到最近可信阶元。

### 3.5 嵌入特征与检索库构建

1. **嵌入提取**（12/13 号脚本系列 + `07h_extract_bioclip25_embeddings.py`）：检索库统一采用**框切图级特征**——FathomNet 框切图 27,342 条 + YOLO 选中框 4,977 条 + 图集插图 1,600 条（插图无检测框，整图提特征）+ 其他兜底 2,228 条，共 36,147 条 1,024 维向量，覆盖 **2,638 / 2,641 个条目（99.9%）**，平均每条目约 13.7 张检索证据；
2. **整帧→框切图替换**（`12d_rebuild_kg_with_boxes.py` 方案A，2026-10 完成）：删除全部 FN 整帧 EntryImage（残留 0），MERGE 框切图节点并挂接 `HAS_IMAGE`，幂等可重跑；多框帧选优效果经 `13h_verify_selection.py` 独立验证（自检索一致率 + YOLO 类名双角度）；
3. **类目覆盖**（`07e_expand_knowledge_base.py`）：知识库类目由早期 185 类扩充至 **8,047 类**（WoRMS 7,240 + FathomNet 807）；
4. **对齐矩阵**（`08_build_alignment_matrix.py`）：构建条目—图像—类目之间的对齐矩阵，作为检索与图谱遍历的桥梁。

### 3.6 GraphRAG 自动构建管线（核心闭环）

`10_graphrag_pipeline.py` 是图谱"自动生长"的引擎，六步全自动化：

| 步骤 | 环节 | 关键设计 |
|---|---|---|
| ① | 图像输入 | ROV / 拖载原位底栖图像，无需人工预处理 |
| ② | 双路 YOLO 检测 | 同权重双视图（960+TTA ∪ 1920）取并集，低 conf 检出 + 逐类 NMS 合并；**宁多勿漏**（机制详见 §2.3） |
| ③ | 双裁剪 | tight 裁剪（干净主体，供检索）+ contextual 裁剪（含生境，供大模型判读） |
| ④ | 嵌入提取 | BioCLIP 2.5 批量 GPU 推理，1,024 维特征 |
| ⑤ | 多视图检索 | 向量检索（**框对框匹配**：查询框切图 ↔ 库内框切图）+ **图谱遍历**（沿 BELONGS_TO 谱系扩展候选）+ YOLO 纲名作为**软提示**参与加权（不做硬性否决） |
| ⑥ | 大模型判读入库 | Qwen2.5-VL-72B 微调模型综合图像、检索证据与知识文本判定，结构化 JSON 写回 Neo4j |

鲁棒性设计：检测误检交由检索排序与大模型判读兜底；写库采用幂等 MERGE，管线可反复重跑不产生脏数据。

### 3.7 推理基础设施

| 组件 | 部署 |
|---|---|
| 视觉大模型 | Qwen2.5-VL-72B「Oceanexus」（深海数据 LoRA 微调 · AWQ INT4 量化 · vLLM 单卡 8,192 上下文服务） |
| 检测 + 嵌入 | GPU0：YOLO11m 34 纲双路 + BioCLIP 2.5 |
| 图数据库 | Neo4j 5.20 容器化（`depth_vlm_neo4j`），7×24 在线服务 |
