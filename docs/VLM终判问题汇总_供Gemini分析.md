# 深海底栖生物物种鉴定系统：VLM 终判不敌向量检索 —— 问题全景与求解请求

> 目标：在不微调 VLM 的前提下，让"VLM 终判"环节超过或有效融合于"BioCLIP 向量检索 rank-1"，提升端到端物种鉴定准确率。请基于下述完整实验证据提出可落地的方案。

---

## 1. 系统背景

深海底栖生物图像鉴定管线（FathomNet + 深海图鉴知识图谱，2,641 个形态物种条目）：

```
场景图 → YOLO 34纲检测 (recall@0.5 88.1%, 纲别acc 95.7%)
      → 检出框 tight 裁剪 (448px)
      → BioCLIP 2.5 ViT-H/14 + LoRA v2 嵌入 (1024维)
      → 库向量余弦 (30,629 张证据图, 2,638 个 mid 质心)
      → 融合重排 cfusion = 0.5×图像分 + 0.5×质心分 (+纲先验 soft)
      → 物种 top-K
```

**检索基线（官方盲测集，1,744 场景 / 6,755 GT 框 / n=5,184 检索对象）**：

| 指标 | base strict | cfusion 定版 |
|---|---|---|
| 物种 top-1 | 48.3% | **49.8%** |
| 物种 top-5 | 67.6% | 69.6% |
| 物种 top-10 | 71.8% | **73.2%** |

- top-10 候选池召回 73.2% 是终判阶段的理论天花板（GT 不在池内生产必错）
- 盲测集与检索库零同源图（构建时按 uuid 族黑名单剔除），GT 来自 FathomNet 官方框级专家标注

## 2. VLM 终判的协议设计

**P6 主协议（11 图选择题）**：查询裁剪图 448px + 检索 top-10 候选（每个 mid 配 1 张类内 medoid 参考图 224px，来自 refs.json，已剔除盲测同源）→ 候选乱序 → 问模型"A-J 哪个选项与查询图是同一物种" → 只取答案字母。temperature=0。

**变体**：
- baseline：纯文字选项（无参考图）
- RAG 版：每候选配 medoid 参考图
- pairwise：每候选单独 2 图"是/否"问题，取首 token logprob 差 z=logp(是)−logp(否) 为连续分数，可与检索分融合

## 3. 全部实验结果（n=500 抽样，同 seed=42 样本可比；另有 n=500 全量标注）

同一样本上检索 cfusion rank-1 = **45.2%**（n=500 口径）/ 49.8%（全量口径）。

### 3.2 乱序复测（P8-C，候选顺序 uuid 种子打乱，暴露位置偏置贡献）

| 模型 | 原序 | 乱序 | Δ | 结论 |
|---|---|---|---|---|
| 本地 27B 思考版 | 30.2% | **16.1%** | −14.1pp | 原序"最优"主要吃位置偏置红利 |
| qwen3.8-max API | 27.0% | **26.2%** | −0.8pp | 最稳，乱序后仍最强 |
| MaaS dsv41f | 29.3% | 23.5% | −5.8pp | |
| qwen3.8-27b API | 25.0% | 22.2% | −2.8pp | |
| 百炼 dsv41f | 23.4% | 23.7% | +0.3pp | 噪声 |
| **Qwen3-VL-32B 本地** | 22.8% | **22.8%** | **±0.0** | **唯一零位置偏置模型，判别力全部真实** |
| 72B-tf | 20.4% | 18.4% | −2.0pp | |

**乱序后全部模型远低于检索 rank-1（45.2%）→ "选字母"类协议下 VLM 真实判别力 ≈ 随机~26%，位置偏置是此前成绩的主要来源（乱序时 raw 输出仍大量选 A）。**

### 3.3 pairwise 协议（P8-A/P8-D，无位置偏置，首 token logprob）

- 27B：纯 pairwise top-1 20.0% << 同子集 rank-1 68.6%；判别间隙 Δz = z(GT对)−z(GT错) = 0.02（纯噪声）；与检索分融合随权重单调变差，最优融合 59.2% 仍显著更差（McNemar p<0.0001）
- 32B：纯 pairwise top-1 仅 8.8%，Δz=−0.14 —— 32B 强项是 11 图选择题，弱项是 yes/no logprob
- **结论：logprob 置信信号在两个模型上都是噪声，pairwise 方向关闭**

### 3.4 其他关键诊断

- **关思考退化**：27B 开源权重关思考 → 11 图题 87% 全答 A（41.7% 假象成绩=无脑抄 rank1）；四层排查确认非部署 bug、非模板问题，是开源权重多图细粒度判别能力的本质缺失；关思考+强制分步形态描述 CoT 仅救回 ~8pp
- **Oracle 上限**：VLM 对&检索错 31 / 检索对&VLM 错 143 / 都对 69 → 并集 54.1% vs 固定回退 rank-1 45.2%（n=449 口径）—— VLM 与检索的错误有互补性，但现有协议无法可靠提取 VLM 的正确判断
- 领域微调 72B（Oceanexus）不优于同代 32B 零样本；商用 API 部署差异 > 模型差异
- 检索侧：Query Expansion 无效；margin 原型质心有害；medoid 全员质心已是检索侧最优（R5-R7 全部关闭）

## 5. 尚未尝试的方向（我们自己的初步想法，请评估/扩展）

1. **知识图谱分层判别**：Neo4j 已含 genus/class 谱系；先判属（top-10 通常 2-4 属，属级参考图池）再同属内细判，把 10 选 1 拆成"4 选 1 + 3 选 1"
2. **开放描述 + 描述库匹配**：VLM 自由描述形态 → 文本嵌入 → 与图谱内物种形态描述库（WoRMS lineage + 图鉴文字）匹配，与检索分融合；不依赖"选字母"
3. **仅对低置信度样本启用 VLM**：检索分有分布信息，只用 VLM 翻案"检索分低/候选得分接近"的样本，其余直接回退 rank-1（选择性预测 / rejection 思路）
4. **多参考图/多轮提问/自一致性**：每候选多张参考图投票、同一问题多次采样投票
5. **视觉证据链 prompt**：先让 VLM 输出结构化形态描述（体形/纹理/附属结构），再在候选描述间做文本比对而非直接选图
