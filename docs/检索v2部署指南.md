## 二、查询端流程（部署目标）

```
用户查询图
   ↓ ①嵌入两次（原图 + 水平翻转），平均归一化        [TTA]
   ↓ ②向量索引 db.index.vector.queryNodes(K=50)      [候选池]
   ↓ ③候选 mid 融合打分，重新排序                     [重排]
       score(mid) = 0.5 × max(该mid候选图相似度)
                  + 0.5 × (查询向量 · 该mid质心)
   ↓ ④返回 top-5 物种条目（mid 级，附最像代表图）
```

## 三、部署步骤

### 1. 预计算质心（一次性；库变更时增量刷新）

```python
# build_centroids.py — 从 Neo4j 拉全库嵌入算 mid 质心, 存 /data/centroids.npz
import numpy as np
from neo4j import GraphDatabase

drv = GraphDatabase.driver("bolt://localhost:7687", auth=("neo4j", "password"))
with drv.session() as s:
    rows = s.run("MATCH (e:EntryImage) WHERE e.embedding IS NOT NULL "
                 "RETURN e.image_id AS id, e.msp_id AS mid, e.embedding AS emb").data()
mids = sorted({r["mid"] for r in rows})
idx = {m: i for i, m in enumerate(mids)}
C = np.zeros((len(mids), 1024), dtype=np.float32)
cnt = np.zeros(len(mids), dtype=np.float32)
for r in rows:
    v = np.asarray(r["emb"], dtype=np.float32)
    C[idx[r["mid"]]] += v; cnt[idx[r["mid"]]] += 1
C = C / np.maximum(cnt[:, None], 1)
C /= np.linalg.norm(C, axis=1, keepdims=True).clip(1e-12)   # L2 归一化
np.savez("/data/centroids.npz", C=C, mids=np.array(mids))
```

### 2. 查询端融合函数（替换"索引直取 top-5"）

```python
def retrieve(q_vec, topk=5, cand_k=50, alpha=0.5):
    """q_vec: 已 TTA 归一化的查询向量 (1024,). 返回 [(mid, score), ...] top-k"""
    hits = vector_index_query(q_vec, k=cand_k)      # 现有索引查询, 取50
    if not hits:
        return []
    scores = {}                                      # mid -> 融合分
    for h in hits:                                   # h: {mid, sim}
        scores.setdefault(h["mid"], [0.0, 0.0])
        scores[h["mid"]][0] = max(scores[h["mid"]][0], h["sim"])
    for mid, (img_s, _) in scores.items():
        c = centroid_of(mid)                         # 查质心缓存
        scores[mid] = alpha * img_s + (1 - alpha) * float(q_vec @ c)
    ranked = sorted(scores.items(), key=lambda x: -x[1])[:topk]
    return ranked
```

### 3. 参数（实验定值，勿随意改）

| 参数 | 值 | 说明 |
|---|---|---|
| cand_k | 50 | 候选池大小；实验中 R@50=96.6%，够用 |
| alpha | 0.5 | 图像分:质心分权重；0.3~0.5 均可，0.5 最稳 |
| TTA | 翻转平均 | 贡献 +0.2pp，若延迟敏感可先只上重排 |
